**Cyber Security Internship Task**



**Overview:-**



This repository contains the tasks completed during the Cyber Security Internship program. The project demonstrates practical skills in reconnaissance, vulnerability assessment, directory enumeration, packet analysis, and security reporting using industry-standard tools.





**Objectives:-**



\- Perform reconnaissance on a target system

\- Conduct vulnerability scanning

\- Analyze network traffic

\- Perform directory enumeration

\- Document findings professionally

\- Upload reports to GitHub



\---



**Tools Used:-**



\- Nmap

\- Nikto

\- OWASP ZAP

\- Burp Suite

\- Wireshark

\- Windows Command Prompt

\- Git \& GitHub

**Tasks Performed:-**



1\. Reconnaissance

Collected target information

Performed port scanning

Identified services and versions



2\. Vulnerability Scanning

Conducted web vulnerability scanning using OWASP ZAP

Identified security misconfigurations

Documented findings



3\. Nikto Scan

Performed web server vulnerability assessment

Identified outdated software and risky configurations



4\. Directory Enumeration

Enumerated hidden directories and files

Identified accessible resources



5\. Packet Analysis

Captured network packets using Wireshark

Analyzed HTTP, HTTPS, DNS, and TCP traffic



6\. Final Vulnerability Report

Compiled all findings

Documented vulnerabilities and recommendations
